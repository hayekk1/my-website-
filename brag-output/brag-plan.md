# LocalFix — brag plan

**What:** A web marketplace that connects customers with trusted local service providers — request, compare offers, book, review.
**For:** People with a broken thing at home and no idea who to call; local pros looking for jobs.
**Angle:** "Something broke." → fixed, in the app's own 4-step flow.
**Hook:** A single drop of water falls, splashes, and "Something broke." slams in. "Who do you call?"
**Tone:** default — punchy, clean, warm.
**Identity (no existing brand, so new):** navy #0E1A2B, fix-orange #FF6A2B, success mint #22C993, paper #F6F3EE. Inter / Inter Display.
**Note:** The project has no UI yet, so the UI is an illustrative mock of the flow described in the proposal. Provider names and prices are sample UI text. No invented stats.
